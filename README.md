# Fumizone

Landing page estática para Fumizone, basada en la propuesta de identidad visual Protected Zone.

## Archivos

- `index.html`: contenido y datos de contacto.
- `style.css`: diseño adaptable.
- `script.js`: preparación de consultas para WhatsApp o correo electrónico.
- `logo.png` e `identidad.jpg`: logo e imagen de marca.

## GitHub Pages

Publicar desde la rama `main`, carpeta `/ (root)`, en Settings → Pages → Deploy from a branch.

No necesita compilación ni dependencias. Las consultas se preparan en el navegador; el visitante elige WhatsApp o su aplicación de correo y confirma el envío.
